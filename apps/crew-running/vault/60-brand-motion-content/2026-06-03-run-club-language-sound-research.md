Data: 2026-06-03
Escopo: teaser Remotion `EstamosChegando`

## Leitura rapida

A copy anterior estava sintetica demais porque falava como produto: "sinal", "chamado", "ritual", "territorio". A linguagem real de run club e mais humana, operacional e social: chegar, correr no proprio pace, encontrar a crew, rota, no drop, depois do corre.

## Padroes encontrados

### 1. Convite simples

Run club bom nao parece manifesto. Parece mensagem de grupo:

- show up;
- just show up and run;
- come run with us;
- cola;
- so chega;
- hoje tem corre.

### 2. Pace sem julgamento

Quase toda comunicacao fala de pace, mas sem performance agressiva:

- all paces;
- run your pace;
- pace groups;
- no pressure;
- no judgment;
- conversational pace;
- no drop.

### 3. Pertencimento concreto

A linguagem boa fala de gente, rota e repeticao semanal, nao de abstracao:

- crew;
- route;
- miles;
- pacers;
- sweepers;
- meet up;
- after the run;
- resenha;
- rota viavel;
- conversa boa.

### 4. Rua/cidade sem slogan vazio

Quando fala de cidade, a melhor linguagem mostra acao:

- explorar a cidade;
- rota;
- sidewalks;
- move together;
- put in the miles;
- get better as a crew.

## Anti-padroes para o teaser

Evitar:

- "a cidade ligou";
- "o sinal ta na rua";
- "nao e post";
- "chamado";
- "veste o ritual";
- "look com rua";
- "territorio aceso".

Essas frases soam como texto gerado para trailer, nao como fala de run club.

## Direcao sonora

Referencia pedida: "James Brown pa". Nao copiar James Brown nem samplear. Traduzir como:

- groove funk de rua;
- breakbeat seco;
- bateria com corpo humano;
- baixo curto;
- palmas/claps sujos;
- vinil/crackle;
- call-and-response de percussao;
- nada de house limpo, nada de trailer epico.
